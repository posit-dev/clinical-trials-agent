## About this agent

This agent answers questions about a simulated clinical study's safety,
disposition, exposure, and demographics in plain language. It is built with [commons](https://github.com/posit-dev/commons). 

Source: [github.com/posit-dev/tlg-agent](https://github.com/posit-dev/tlg-agent)

### Data

All answers are computed over a CDISC ADaM sample dataset generated by
[`random.cdisc.data`](https://insightsengineering.github.io/random.cdisc.data/)
and loaded into an in-process DuckDB. Four analysis datasets are available:

- **`adsl`** — subject-level analysis (one row per patient: arm, demographics, disposition)
- **`adae`** — adverse events
- **`adex`** — study drug exposure
- **`adlb`** — laboratory results

### Tables, listings, and graphs

Standard questions are answered from validated measures, which use code from Insight Engineering's [TLG Catalog](https://github.com/insightsengineering/tlg-catalog).
