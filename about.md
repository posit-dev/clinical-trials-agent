## About Clinical Trials Agent

Clinical Trials Agent answers questions about a simulated clinical study's
safety, efficacy, survival, disposition, exposure, demographics, and laboratory
results in plain language. It is built with
[commons](https://github.com/posit-dev/commons).

Source: [github.com/posit-dev/tlg-agent](https://github.com/posit-dev/clinical-trials-agent)

### Data

The agent uses CDISC ADaM sample data generated by
[`random.cdisc.data`](https://insightsengineering.github.io/random.cdisc.data/).
Six analysis datasets are available to measures and to governed SQL through
an in-process DuckDB:

- **`adsl`** - subject-level analysis (one row per patient: arm, demographics, disposition)
- **`adae`** - adverse events
- **`adex`** - study drug exposure
- **`adlb`** - laboratory results
- **`adaette`** - adverse-event time-to-event and event-count parameters
- **`adtte`** - efficacy time-to-event endpoints, including OS, PFS, and EFS

### Tables, listings, and graphs

Standard questions are answered by trusted measures, including measures that
render plots directly. These measures reproduce or adapt recipes from Insights
Engineering's [TLG Catalog](https://github.com/insightsengineering/tlg-catalog).

Questions outside measure coverage fall back to custom SQL applied over the analysis datasets.
